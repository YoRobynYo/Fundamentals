Variables 📦

Variables are like boxes that store information in our factory. You can put numbers, words, or true/false answers inside them and use them later in your program.

Examples

We can make simple boxes using let, const, and var in JavaScript:

  • let – creates a box you can change later.
  • const – creates a box that cannot change after you set it.
  • var – an old way to make a variable. It is no longer used because it has been replaced by let and const.
let batchNumber = 7; // current batch of popcorn const machineStatus = 'ON'; // status of the popcorn machine

We can also store yes/no answers using true or false:

let isSaltAvailable = true; let isSugarAvailable = false;

💡 A Simpler Fundamental: Template Literals

To combine text and variables, we will learn a simple and modern fundamental called a Template Literal. It's easier to read and write than older methods.

How It Works: Backticks and Placeholders

There are just two rules:

  1. Start and end the message with a backtick (`), not a normal quote.
  2. When you want to add a variable, use the placeholder: ${...}.

Example:

// Notice the backticks and the ${...} placeholder let message = `Batch ${7} is ready.`; console.log(message); // The output will be: Batch 7 is ready.

Step-by-Step Guide to See Your Code Work

  1. Create Variables: Use let to create the "boxes" for your information.
  2. Build a Message: Use a Template Literal (`...${}...`) to write your message and put your variables inside the placeholders.
  3. Print to the Console: To see the result of your code, you must "print" it. We do this by wrapping our message inside console.log().

What is the Console?

The console is like a simple screen where you can see messages from your code. The console.log() command means "show my message on that screen." In our exercises, the "output" box below your code acts as your console.

Demonstration: Putting It All Together

Here is how you would use all three steps to create a variable and print a message:

// Step 1: Create a variable for the flavor.
let flavor = "Caramel";

// Step 2 & 3: Build a message and print it.
console.log(`The flavor of the day is: ${flavor}`);

This will print "The flavor of the day is: Caramel" to the output!

Loops 🔁

    
Loops are the conveyor belts and automated machines in our factory. They are programmed to do the same task
      over and over, so you don't have to do it manually!


    
Example: Making a Batch of Popcorn

    
Imagine a machine that has to make exactly 5 bags of popcorn. You can program a loop to do this automatically.
    


    

      
💡 How a 'for' loop works

      
Let's look at the three parts inside the parentheses for ( ... ):

      
    
        
  • let i = 1; — The counter variable, starting at 1.
    • 
        
  • i <= 5; — The loop will keep running as long as this is true.
    • 
        
  • i++ — Increase the counter by 1 after each run.
    • 
      

    


    

      
💡 Quick Reminder

      
Remember how we used + to join text and variables? We'll use that again inside loops!

    


    
// This loop runs 5 times
      for (let i = 1; i <= 5; i++) { console.log("Bag " + i + " is ready!"); } 


        
Step-by-Step Guide

        
    
          
  1. Start with for ( ... ).
    2. 
          
  2. Set up a counter: let i = 0;.
    3. 
          
  3. Add a condition to stop: e.g., i < 5;.
    4. 
          
  4. Add a step to update the counter: i++.
    5. 
          
  5. Place the repeatable job inside { }.
    6.

Functions 🧩

    
Functions are like different stations in a factory. You build each station to do one specific job, and then you
      can run them in order to get a final product.

    
Imagine a popcorn factory. There’s a station for turning on the lights, a station for making the popcorn, and a
      station for packing it. Each station is a function!


    
Examples from the Factory

    
A simple station might just turn on the lights. It doesn't need any extra information to do its job.

    

      function turnOnLights() {
      console.log("Flick! The factory lights are now on.");
      }
    


    
A more complex station needs instructions. Our popcorn machine needs to know what flavor to
      make. This extra information is called a parameter.

    

      function makePopcorn(flavor) {
      console.log("Starting the machine to make " + flavor + " popcorn...");
      console.log("🍿 Your " + flavor + " popcorn is ready!");
      }
    


    
Running the Factory

    
Now, we can run our factory by "calling" each function in order. Notice how we give the
      makePopcorn
      function the flavor it needs!
    

    

      // A day at the factory:
      turnOnLights();
      makePopcorn('caramel');
      makePopcorn('cheesy');
    


    
Step-by-Step Guide

    
    
      
  1. Start with the word function followed by a clear name for your station (e.g.,
        runMachine).
      
    2. 
      
  2. Add parentheses (). If your function needs information, put parameter names inside (e.g.,
        (flavor)).
      
    3. 
      
  3. Write the instructions for your station inside curly brackets { }.
    4. 
      
  4. To run your station, "call" it by writing its name with parentheses: runMachine();
    5.

Conditionals ❓

    
Conditionals are the sensors and decision-making systems in our factory. They constantly ask questions to
      ensure
      everything is running safely and correctly. It's like a sensor asking: "Is the popper hot enough?" If yes, start
      popping; if no, wait.


    
    

      
💡 How 'if/else' works

      
The code for making a decision has a special layout. Think of it like a fork in the road.

      
    
        
  • if ( ... ) — This is where you ask your question. The question, or "condition," goes inside
          the
          parentheses.
    • 
        
  • The first { ... } — This is the "Yes Path." The code inside these brackets runs only if the
          answer to your question is true.
    • 
        
  • else — This keyword means "otherwise."
    • 
        
  • The second { ... } — This is the "No Path." The code here runs only if the answer to your
          question is false.
    • 
      

    


    
Examples from the Factory

    
Now that we know the layout, let's see it in action. This sensor checks if the salt level warning light is on.
    

    

      let isWarningLightOn = true;
      if (isWarningLightOn) {
      console.log("ALERT: Check the salt levels immediately!");
      } else {
      console.log("All systems normal. The salt level is fine.");
      }
    

    
Here, a temperature sensor checks the popcorn popper. The machine will only start if the temperature is over
      170
      degrees.

    

      let popperTemp = 185;

      if (popperTemp > 170) {
      console.log("Temperature is perfect! Starting the popper.");
      } else {
      console.log("Waiting for the popper to heat up...");
      }
    


    
Step-by-Step Guide

    
    
      
  1. Start with if and write your question (the condition) inside ( ).
    2. 
      
  2. Put the "yes" actions inside the first set of curly brackets { }.
    3. 
      
  3. Optionally, add else and put the "no" actions in its own { }.
    4.

Operators ⚡

    
Operators are the special tools in our factory. They help us do math, make comparisons, and check conditions to
      keep everything running smoothly.


    
Examples from the Factory

    
We use arithmetic operators to track our inventory. For example, the corn supply in the storage room:

    

      let cornSupply = 500;
      let usedCorn = 80;
      let remainingCorn = cornSupply - usedCorn;
      console.log("Remaining corn: " + remainingCorn); // Output: Remaining corn:
        420
    


    

      
💡 Multiply & Divide

      
These operators help with packing crates:

      
    
        
  • * — Multiply (e.g., 12 bags per crate × 10 crates)
    • 
        
  • / — Divide (e.g., 120 bags ÷ 12 bags per crate)
    • 
      

    


    

      let totalBags = 120;
      let bagsPerCrate = 12;
      let cratesFilled = totalBags / bagsPerCrate;
      console.log("Crates filled: " + cratesFilled); // Output: Crates filled: 10
    


    

      
💡 Comparison Operators

      
These are the factory sensors! They answer yes/no questions:

      
    
        
  • > — Is the first value greater than the second?
    • 
        
  • < — Is the first value less than the second?
    • 
        
  • === — Is the first value exactly equal to the second?
    • 
      

    


    

      let popperTemp = 185;
      let isHotEnough = popperTemp > 170;
      console.log("Is the popper ready? " + isHotEnough); // Output: true
    


    

      
💡 Quick Reminder: Concatenation

      
The + operator can join text and variables, like labeling crates:

    


    

      let batchID = "A-102";
      let status = "complete";
      let report = "Batch #" + batchID + " is " + status + ".";
      console.log(report); // Output: Batch #A-102 is complete.

The Bag Counter: The 'Increment' Operator

    
At the end of the belt, there's a digital counter. Every time a finished bag passes the sensor, the count needs
      to go up by exactly one.


    

      
💡 New Shortcut: The 'Add One' Button (++)

      
The increment operator (++) is the ultimate shortcut for adding exactly 1 to a
        variable's current value. This is the same tool we saw inside our for loops!

    


    

      let bagsMadeThisHour = 0;

      bagsMadeThisHour++; // A bag passes the sensor. The count is now 1.
      bagsMadeThisHour++; // Another bag passes. The count is now 2.

      console.log(bagsMadeThisHour + " bags have been made."); // Output: 2 bags have been
        made.
    


    
The Control Room: Smart Switches

    
These "smart switches" let us combine multiple true/false questions to make one single, smart decision for our
      factory's safety and alert systems.


    

      
💡 Smart Switch 1: The 'OR' Operator (||)

      
The OR operator (||) is for alerts. It checks if at least one
        thing is true. The whole thing is true if the left side is true, OR if the right side is true (or
        if both are).

    


    
The factory alarm should sound if the boiler pressure is too high OR if the belt is jammed.

    

      let pressure = 210;
      let isBeltJammed = false;
      if (pressure > 200 || isBeltJammed) {
      console.log("WEE-OO! WEE-OO! Factory Alert!");
      } else {
      console.log("All systems are running smoothly.");
      }
    


    

      
💡 Smart Switch 2: The 'AND' Operator (&&)

      
The AND operator (&&) is for safety. It checks if two things are both
          true at the same time. The whole thing is only true if the condition on the left AND
        the
        condition on the right are true.

    


    
For our main popper to start, the power must be on AND the safety hatch must be closed.

    

      let powerIsOn = true;
      let isHatchClosed = false; // Oh no, someone left it open!
      if (powerIsOn && isHatchClosed) {
      console.log("All safety checks passed. Starting the machine!");
      } else {
      console.log("DANGER: Cannot start machine. A check failed.");
      }
    


    

      
Tools We've Learned in Part 2

      
    
        
  • Increment Operator: ++ for adding one.
    • 
        
  • Logical Operators: || (OR) and && (AND) for making smart
          decisions.
    •

Events - Introduction ⚡

    
Welcome to the Main Control Room! Look at all these cool buttons on the control panel! Go on, try to click
      them... nothing happens. Why not?

    
Because we haven't "plugged them in" yet! Buttons alone can't do anything—they need instructions from JavaScript.
      To wire them up, we use addEventListener.


    

      
💡 How to Wire Up a Button

      
Wiring a button takes three steps:

      
    
        
  1. Get the Button: Grab the button from the HTML using document.getElementById()
          or another DOM selector.
    2. 
        
  2. Listen for a Click: Tell your button to "listen" for a 'click' event.
    3. 
        
  3. Give it a Job: Define a function that runs when the button is clicked.
    4. 
      

      
Think of it like wiring a real button in the factory: connect the wire, attach the signal, and tell the machine
        what to do.

Objects 📦

    
An object is like the supervisor's backpack! While an array is a simple list, an object is a
      special container with labeled compartments. Each compartment has a name (a property) and holds
      something useful (a value). Objects help us keep related information organized in one place.
    


    
Example: The Supervisor's Backpack

    
Let's build a supervisor's backpack with compartments for their keys, clipboard, and walkie-talkie.


    

      
💡 How to Build an Object

      
We create an object using curly braces { }. Inside, we list the properties and their values,
        separated by a colon :.

      

        let objectName = {
        propertyName1: "value1",
        propertyName2: "value2"
        };
      

    


    

      let supervisorBackpack = {
      keys: "Warehouse keys",
      clipboard: "Daily checklist",
      walkieTalkie: "Channel 5",
      hasSafetyGoggles: true
      };
    


    
Peeking Inside a Compartment

    
To see what's inside a specific compartment, we use "dot notation."


    

      
💡 Using a Dot (.) to Access Properties

      
The dot (.) lets you connect the object's name to the property you want to see. Think of it as
        peeking into a labeled compartment.

      

        objectName.propertyName
      

    


    

      // Let's see what's in the 'keys' compartment
      console.log(supervisorBackpack.keys); // Output: Warehouse keys

      // Let's check if the supervisor has goggles
      console.log(supervisorBackpack.hasSafetyGoggles); // Output: true
    


    
Adding a New Compartment

    
What if the supervisor wants to add snacks to their backpack? We can add a new property at any time!

    

      // Add a new 'snacks' compartment
      supervisorBackpack.snacks = "An apple";
      console.log(supervisorBackpack.snacks); // Output: An apple

💡 A New Array Tool: The '.push()' Method

        
The .push() method is a special tool for arrays. It lets you add a new item to the very end of

        // Give the backpack a list of snacks
